## Verified evidence

The November 8 owner workflow used a live CPSC notice and validated Gemini extraction, a deliberate human-reviewed rule, a buyer-approved USD 49.00 PayPal sandbox capture, and a separate approved courtesy refund. PayPal GET confirmed the refund completed. A response-link parser issue initially left the local result unknown; read-only discovery recovered that existing result. Repeating execution returned the same durable attempt.

The recorded sandbox evidence identifies `UNTAGGED_LOCAL_BUILD`, the build used when that evidence was created. Publishing this source does not change the evidence timestamp or pretend the transaction ran from a later Git commit. The actual evidence and receipt are in `docs/reports/sandbox-workflow-completed.json` and `docs/reports/RR-001-sandbox-receipt.json`.

Current test evidence: 111 unit/component checks, 26 PostgreSQL integration checks with mocked providers, and six browser workflows passed during local verification. UI refinements subsequently passed production compilation, type checking, lint, and the browser workflow suite. These are observations of this prototype, not a broad AI accuracy or production certification claim.

## Release boundaries

The public source can run in simulation without provider keys. Actual sandbox purchases and refunds require a private owner setup and deliberate buyer/operator approvals. Provider credentials, database volumes, installed dependencies, build output, and browser traces are excluded by Git ignore rules. No real customer data is used.

Public application hosting, the final demonstration video, and Devpost entry submission are separate tasks and have not been completed by this source push.
